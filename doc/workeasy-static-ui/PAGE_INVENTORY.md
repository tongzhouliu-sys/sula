## 范围说明

- 页面范围以当前账号在 2026-08-24 实际可见的前台入口为准，没有尝试访问权限之外的管理页面。
- 原站“发布空间”入口在盘点时没有打开独立内容页，因此静态版保留入口与本地提示，不虚构生产页面。
- 会产生真实提交、审批、删除、授权、下载或消息发送的按钮，在静态版只显示本地提示。
- 所有账号、邮箱、工号和登录名均已脱敏或替换为演示值。
- 静态版不包含后台接口、Cookie、访问令牌、密码、真实业务数据或生产鉴权逻辑。
